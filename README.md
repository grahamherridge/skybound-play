# Skybound: First Flight

Play: https://grahamherridge.github.io/skybound-play/

Choose **Big sky** for the next visual review (source PR remains Draft). The oversized diagonal hillside and perched cottages have been removed. Gentle lower hills, distant village, the Foldwood oak and wren, and the greenhouse Landing Garden remain. Flight geometry, all 16 stamps, checkpoints and physics are unchanged. Pause and reduced motion are supported.

A/D or arrows steer; hold Space to thrust, release to coast; R retries. Touch controls are provided. Watch the wren for about ten seconds, approach gently, or swoop past and let it settle again.

This release also retains the authored Perilous Parish flight, earlier living-world habitats and the existing selectable game modes.
