# Skybound: First Flight

Play: https://grahamherridge.github.io/skybound-play/

A/D or arrows steer; hold Space to thrust, release to coast; R retries. Touch controls are provided. Choose Lantern Reach / Collector to chase named postmarks and connected STACK x3 through x18. Breaking Flow keeps earned points and postmarks.

Comic pickup celebrations: a small x1 POP, brighter x2 sparks, big x3 COMBO ink stars and rings, then layered stacked fireworks up to Legendary Flow. Existing scoring and flight are unchanged. Mute and reduced motion are supported.

Compiled static playable only; development source/history remain private. No remote assets, tracking, runtime dependencies or backend.
