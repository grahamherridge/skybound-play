# Skybound: First Flight

Play: https://grahamherridge.github.io/skybound-play/

A/D or arrows steer; hold Space for thrust, release to coast; R retries. Touch controls are provided. Big sky opens first; select Lantern Reach / Collector for the stacking Flow experiment.

Three stamps earn a named postmark. Connected airborne phrases build STACK x3 through x18, with real multiplied completion bonuses, escalating ink-and-paper celebrations and chimes. Breaking Flow keeps all points and postmarks already earned. The receipt separates pickup points, multiplied bonuses and current/best connection. High Drop supports x3 to x6; Level 2 keeps checkpoint teaching rewards.

This repository contains only the compiled static playable. Development source/history remain private. No backend, tracking, remote assets or runtime dependencies.
