# Skybound: First Flight

Play: https://grahamherridge.github.io/skybound-play/

Choose **Big sky** for the next visual review (source PR remains Draft). The oversized diagonal hillside and perched cottages have been removed. Gentle lower hills, distant village, the Foldwood oak and wren, and the greenhouse Landing Garden remain. Flight geometry, all 16 stamps, checkpoints and physics are unchanged. Pause and reduced motion are supported.

A/D or arrows steer; hold Space to thrust, release to coast; R retries. Touch controls are provided. **Full screen** beside Pause expands the game and controls together; **Exit full screen** returns to the page. Portrait and landscape keep the full scene in proportion. On phones, landscape provides the largest flight view. Browser/system exit is also supported. Watch the wren for about ten seconds, approach gently, or swoop past and let it settle again.

This release also retains the authored Perilous Parish flight, earlier living-world habitats and the existing selectable game modes. Compiled from private source revision `a54b5b6`. The main playable is the exact verified standalone HTML (SHA-256 `0e274da179b3dcf3dec089ff42e046fd9b43b645531ac401d67822836c299004`). 212 native tests, production build and five focused full-screen browser scenarios passed, including the exact standalone artifact, portrait/landscape layouts and real touch input.
